# Reusable Prompt Templates

## Candidate generation

```text
根据以下专业方向、导师偏好、案例限制和资料条件，生成5—8个可比较的硕士论文候选题。每个候选题说明核心研究问题、案例选择理由、主要证据入口、可能方法、创新来源和最大风险。暂不撰写开题报告。
```

## P0 screening

```text
请对以下候选题进行P0初筛。分别评价研究重要性、学科匹配、案例独特性、公开资料可得性、已有研究重复风险和导师接受风险。输出“通过、条件通过或不通过”，并列出进入P1前必须验证的三项证据。
```

## P1 validation

```text
围绕该选题进行P1证据核验。建立“研究命题—所需证据—现有来源—来源状态—缺口—替代方案”表格。优先使用官方文件和公司一手资料。至少试做一张数据表或一次文本编码，并据此判断选题能否进入开题写作。
```

## Advisor-feedback correction

```text
请把导师反馈拆分为题目、研究范围、重要性、证据、方法、学科定位、写作和格式问题。判断每条反馈要求改变的是措辞还是研究设计，并给出最小但完整的联动修改方案。不要只改标题。
```

## Main question and subquestions

```text
基于已通过P1的证据，为该案例提炼一个核心研究问题和3—4个子问题。主问题需要形成明确机制链，子问题分别对应动因、内部化、运行机制和结果边界，并说明每个问题对应的数据、方法和论文章节。
```

## Literature review

```text
请依据已核验文献，按研究主题和观点分歧组织文献综述。每个主题依次说明研究对象、主要观点、代表性证据、研究分歧和局限，最后自然引出本研究问题。禁止逐篇罗列，禁止使用未核验文献，禁止把“没有人研究该公司”作为主要研究缺口。
```

## Method audit

```text
请审查当前研究方法。对每种方法说明其回答的子问题、所需数据、具体操作和不可替代性。把时间线、比例计算、图表、同业参照和证据三角验证等分析操作与正式研究方法区分开。删除不能直接服务主问题的方法。
```

## Proposal consistency review

```text
请检查开题报告中题目、主问题、子问题、理论、方法、证据、创新点、章节和预期结论是否一一对应。重点识别强因果、空泛创新、未核验政策、无法执行的方法和只为防止质疑而存在的句子。输出必须修改、建议修改和可以保留三类意见。
```

## Version-preserving Word revision

```text
请在不覆盖原文件、不改变既有字体颜色和版式的前提下完成局部修订，另存为下一版本。只修改指定板块，完成后逐页检查，并报告源版本、输出版本、修改内容、保留内容和文件位置。
```

## Defense stress test

```text
请模拟开题答辩，从研究重要性、案例选择、研究增量、证据充分性、方法必要性、因果边界和可完成性七个方面提出尖锐问题。每个问题给出基于现有开题报告和证据的简洁回答，并标记仍需补证的问题。
```

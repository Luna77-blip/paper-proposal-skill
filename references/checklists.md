# Checklists

## Intake

- [ ] Degree and discipline are known.
- [ ] Advisor feedback has been obtained verbatim where possible.
- [ ] School template and model proposals are available.
- [ ] Deadline, length, and required sections are known.
- [ ] Data access and excluded cases are recorded.
- [ ] File-editing and overwrite permissions are clear.

## Topic

- [ ] The topic contains an important research problem.
- [ ] The case reveals a mechanism, contradiction, or boundary condition.
- [ ] The case is not selected only because it is recent or famous.
- [ ] The research scope is neither a single technical detail nor an uncontrolled collection of outcomes.
- [ ] The title does not pre-commit to a positive result.

## P0

- [ ] Importance is explained.
- [ ] Disciplinary fit is explicit.
- [ ] Evidence entry points exist.
- [ ] Differentiation is more than a company substitution.
- [ ] Advisor and group restrictions are satisfied.

## P1

- [ ] Core facts have primary sources.
- [ ] A timeline or process sequence exists.
- [ ] Multi-year or multi-stage evidence exists.
- [ ] Definitions and boundaries are known.
- [ ] A pilot analysis has been completed.
- [ ] Core literature is verified.
- [ ] Unsupported causal claims have been removed.

## Research questions

- [ ] There is one main question.
- [ ] There are three subquestions by default; a fourth is retained only when it has independent evidence, method, and chapter value.
- [ ] Case background is not counted as a research question unless it is analyzed.
- [ ] Each subquestion maps one-to-one to evidence, method, and an analysis chapter.
- [ ] The subquestions jointly answer the main question.
- [ ] The result question does not presume effectiveness.

## Literature

- [ ] Bibliographic details are verified.
- [ ] Cited claims are checked against the source.
- [ ] Full-text status is recorded separately.
- [ ] The review is organized by debate or mechanism.
- [ ] The gap follows from the review.
- [ ] Unverifiable and title-only sources are excluded.

## Methods

- [ ] Every method answers a research question.
- [ ] Required data are accessible.
- [ ] Method names follow disciplinary conventions.
- [ ] Analytical operations are not presented as independent methods.
- [ ] The observation period and inclusion rules are explicit.

## Proposal

- [ ] Title, question, methods, evidence, chapters, and conclusion align.
- [ ] The case-introduction chapter is separate from the core case-analysis chapters.
- [ ] Chapters 3–6 have a clear sequence and do not repeat the same evidence under different labels.
- [ ] Each core analysis chapter title expresses the analytical logic of one subquestion.
- [ ] The research-framework diagram mirrors the question and chapter structure.
- [ ] Theory explains the mechanism rather than decorating the review.
- [ ] Significance and contribution are evidence-bounded.
- [ ] Key tables include source, unit, period, and definition.
- [ ] Policy and regulatory statements are current.
- [ ] In-text citations match the reference list.

## Document delivery

- [ ] The source file was preserved.
- [ ] The output has a new version number.
- [ ] User formatting was preserved unless change was requested.
- [ ] Editable chart and diagram sources are retained.
- [ ] When a framework diagram was revised, the original was preserved and the new version remains editable.
- [ ] All pages were visually inspected.
- [ ] The final response states the exact output location.

## Defense

- [ ] The importance can be explained in one sentence.
- [ ] The case-selection logic is explicit.
- [ ] The research increment is not “no one studied this company.”
- [ ] The evidence plan is executable.
- [ ] Method choices can be defended.
- [ ] Causal and generalization boundaries are understood.
- [ ] Remaining evidence gaps have a collection plan.
